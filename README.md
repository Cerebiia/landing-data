# Cerebiia Data - Landing Page

Plataforma web todo-en-uno para el cumplimiento de la Ley 1581 de 2012: recolección, validación, auditoría y comunicaciones masivas de datos personales.

## 🎨 Cambios Realizados en Refactorización UI/UX

### Página Principal (Cerebiia Data)
- **Hero Section**: Diseño limpio y moderno con gradientes de fondo
- **Features Grid**: Grid responsivo con iconos estilizados y efectos hover
- **Pricing Cards**: Rediseño completo con badges, checkmarks mejorados y botones CTA estilizados
- **Clients Carousel**: Carrusel infinito de logos con animación automática y tamaño aumentado
- **Case Study**: Sección de caso de éxito con video de Instagram integrado y modal de reproducción
- **Footer**: Estandarización de 3 columnas con información de contacto

### Página de Proyectos
- **Hero Section**: Heading específico con diseño impactante
- **Stats Bar**: Barra horizontal de estadísticas con iconos y efectos hover
- **Services Grid**: Grid de 4 tarjetas de servicios con diseño profesional
- **Portfolio Showcase**: Layout alternante de proyectos con tarjetas mejoradas
- **CTA Section**: Reducción de espaciado y eliminación de repetición de contacto
- **Footer**: Consistente con la página principal

### Mejoras Generales
- **Espaciado**: Reducción de espacios verticales para mejor ritmo visual
- **Tipografía**: Consistencia en tamaños y pesos de fuentes
- **Colores**: Ajuste de textos blancos en fondos blancos al color de marca navy
- **Animaciones**: Transiciones suaves y efectos hover mejorados
- **Organización**: Estructura de carpetas optimizada para assets

### Organización de Archivos
- `src/assets/clients/` - Logos de clientes renombrados (client-1.png a client-4.png)
- `src/assets/projects/` - Logos de proyectos específicos
- `public/favicon.ico` - Nuevo favicon personalizado

### Tecnologías
- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Lucide Icons

## Development
